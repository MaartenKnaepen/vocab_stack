# Render.com Deployment Checklist

## Pre-Deployment ✅

- [ ] **Test locally**
  ```bash
  uv run reflex run
  ```

- [ ] **Run tests**
  ```bash
  uv run pytest tests/
  ```

- [ ] **Check migrations**
  ```bash
  uv run alembic current
  uv run alembic upgrade head
  ```

- [ ] **Commit all changes**
  ```bash
  git status  # Check nothing is uncommitted
  git add .
  git commit -m "Ready for Render deployment"
  git push origin main
  ```

---

## Deployment to Render ✅

- [ ] **Sign up for Render**
  - Go to https://render.com
  - Click "Get Started for Free"
  - Sign up with GitHub

- [ ] **Create Blueprint deployment**
  - Click "New +" → "Blueprint"
  - Connect your vocab_stack repository
  - Render auto-detects `render.yaml`
  - Click "Apply"

- [ ] **Wait for build** (5-10 minutes)
  - Monitor in "Events" tab
  - Check "Logs" tab for any errors

---

## Post-Deployment ✅

- [ ] **Copy your app URL**
  - Example: `https://vocab-stack.onrender.com`

- [ ] **Update ALLOWED_ORIGINS**
  - Go to "Environment" tab
  - Add variable:
    ```
    ALLOWED_ORIGINS = https://vocab-stack.onrender.com
    ```
  - Click "Save Changes"

- [ ] **Test the application**
  - [ ] Open app URL in browser
  - [ ] Sign up for an account
  - [ ] Log out and log back in
  - [ ] Create a topic
  - [ ] Add flashcards
  - [ ] Start a review session
  - [ ] Test review functionality
  - [ ] Check settings page

- [ ] **Verify database persistence**
  - Add some data
  - In Render, click "Manual Deploy" → "Deploy latest commit"
  - Wait for redeploy
  - Check that your data is still there ✅

---

## Configuration Verification ✅

- [ ] **Environment variables set**
  - [ ] `DATABASE_URL=sqlite:////data/vocab_stack.db`
  - [ ] `SECRET_KEY` (auto-generated by Render)
  - [ ] `ENV=production`
  - [ ] `PYTHON_VERSION=3.11`
  - [ ] `ALLOWED_ORIGINS=<your-render-url>`

- [ ] **Persistent disk configured**
  - [ ] Disk name: `vocab-data`
  - [ ] Mount path: `/data`
  - [ ] Size: 1GB (or more)

- [ ] **Auto-deploy enabled**
  - Should be on by default
  - Check in service settings

---

## Security Final Check ✅

- [ ] **SECRET_KEY is secure**
  - Auto-generated by Render (should be random)
  - Or manually generated with:
    ```bash
    python3 -c "import secrets; print(secrets.token_urlsafe(32))"
    ```

- [ ] **ALLOWED_ORIGINS is correct**
  - Set to your actual Render URL
  - Not set to `*` (wildcard)

- [ ] **HTTPS is working**
  - Visit your app with `https://`
  - Check for padlock icon in browser

- [ ] **No sensitive data in code**
  - `.env` file is in `.gitignore` ✓
  - No hardcoded passwords or keys ✓

---

## Optional: Keep App Warm ✅

To avoid cold starts on free tier:

- [ ] **Set up uptime monitoring**
  - Sign up at https://uptimerobot.com (free)
  - Add HTTP monitor for your Render URL
  - Check interval: 14 minutes
  - This keeps your app from spinning down

---

## Monitoring Setup ✅

- [ ] **Bookmark your Render dashboard**
  - Quick access to logs and metrics

- [ ] **Check logs regularly**
  - First week: Daily
  - After stable: Weekly

- [ ] **Monitor disk usage**
  - Render dashboard → Metrics
  - 1GB should be plenty for 5 users

---

## Share with Users ✅

- [ ] **Document the URL**
  - Share: `https://vocab-stack.onrender.com`

- [ ] **Warn about cold starts**
  - First request after 15 min inactivity = 30s delay
  - Normal for free tier

- [ ] **Create first accounts**
  - Test with all 5 users
  - Ensure everyone can sign up

---

## Backup Strategy ✅

- [ ] **Plan for backups**
  - Manual: Use Render Shell to export database
  - Schedule: Before major updates
  - Command: `sqlite3 /data/vocab_stack.db .dump > backup.sql`

- [ ] **Document restore process**
  - Keep instructions for importing backup if needed

---

## Future Maintenance ✅

- [ ] **Test before pushing to main**
  - Remember: Push to main = auto-deploy!
  - Test locally first

- [ ] **Monitor resource usage**
  - Check if 512MB RAM is enough
  - Watch disk space (1GB limit)

- [ ] **Update dependencies periodically**
  ```bash
  uv lock --upgrade
  git commit -am "Update dependencies"
  git push origin main
  ```

---

## Rollback Plan ✅

If something goes wrong:

- [ ] **Know how to rollback**
  - Render dashboard → "Manual Deploy"
  - Select previous successful deploy
  - Click "Deploy"

- [ ] **Or revert git commit**
  ```bash
  git revert HEAD
  git push origin main
  # Render auto-deploys the revert
  ```

---

## Success Criteria ✅

Your deployment is successful when:

- ✅ App accessible at Render URL
- ✅ Can sign up and log in
- ✅ Can create topics and flashcards
- ✅ Review sessions work
- ✅ Data persists after redeployment
- ✅ No errors in logs
- ✅ All 5 users can access
